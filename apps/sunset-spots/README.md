# שקיעה — אפליקציית מקומות שקיעה

ה־Brief המלא: [`ideas/2026-10-18-sunset-spots-app.md`](../../ideas/2026-10-18-sunset-spots-app.md)

## מה יש כרגע (ימים 1–3)
- שעת השקיעה הבאה וספירה לאחור עד אליה, לפי המיקום שלך
- מצפן שמראה לאן השמש שוקעת. בטלפון הוא מסתובב עם המכשיר, ומודיע כשהטלפון מכוון בדיוק לשקיעה
- כיוון השקיעה (16 כיווני מצפן ומעלות) ושעת תחילת שעת הזהב
- אם אין הרשאת מיקום, מוצגת השקיעה בתל אביב
- **מקומות לשקיעה סביבך** (עד 10 ק"מ) מ־OpenStreetMap: נקודות תצפית, פסגות, פינות פיקניק, ספסלים וסככות. ספסלים צמודים מאוחדים למקום אחד
- דירוג לפי נוף, נגישות ונעימות, עם בורר "נוחות / מאוזן / נוף" וכפתור Waze לכל מקום
- **בדיקת קו האופק (יום 3):** לכל אחד מ־18 המקומות המבטיחים נדגמות 16 נקודות גובה לאורך קו של 35 ק"מ לכיוון השקיעה. החישוב כולל תיקון לעקמומיות כדור הארץ ולשבירת האור. המקומות מקבלים תגית: "אופק פתוח", "אופק ים" או "האופק חסום חלקית"

## הרצה בטלפון
צריך מחשב עם Node.js 22 ומעלה, והאפליקציה **Expo Go** בטלפון.

```bash
cd apps/sunset-spots
npm install
npx expo start
```

סורקים את קוד ה־QR עם Expo Go (באנדרואיד) או עם המצלמה (באייפון). הטלפון והמחשב צריכים להיות באותה רשת Wi‑Fi.

גרסת דפדפן: `npx expo start --web`. בדפדפן אין מצפן, אז הוא מוצג כשהצפון למעלה.

## בדיקות
```bash
npm test          # חישובי השמש
npm run typecheck
npx expo lint
```

## הערות
- **SunCalc 2.x** מחזירה כיוון במעלות מהצפון, עם כיוון השעון (לא ברדיאנים מהדרום כמו בגרסה 1).
- ציון ה**נוף** מבוסס על קו האופק (70%) ועל סוג המקום ותגית `direction` (30%). אם בדיקת הגובה נכשלת, הציון חוזר להיות מבוסס רק על סוג המקום. ה**נגישות** היא כרגע רק המרחק ממך.
- נתוני הגובה (Copernicus DEM, ~90 מ') לא כוללים בניינים ועצים. לכן מקום בעיר יכול לקבל "אופק פתוח" גם כשבניין חוסם אותו.
- **לפני השקה בחנות:** השימוש החינמי ב־Open-Meteo מיועד לשימוש לא מסחרי. לאפליקציה מסחרית כנראה צריך מנוי, ולכן צריך לבדוק את תנאי השימוש העדכניים.
- הקריאות ל־Overpass ול־Open-Meteo לא נבדקו מול השרתים האמיתיים, כי הרשת של סביבת הפיתוח חסמה אותם. הן נבדקו רק מול תשובות לדוגמה במבנה של שני השירותים.
- המפה של Mapbox תיכנס בהמשך. היא דורשת מפתח Mapbox ו־development build, כי היא לא רצה ב־Expo Go.
